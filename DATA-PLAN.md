### Anthony's Shiny collection export (ownership truth)
**Used by**: seedBinder (ownership join), card detail values
**Test command**: `python3 csv read of ~/workspace/user/files/ShinyExport-6533e14c87234a7792ff9a660a4c26b6_2_tm5t.csv`
**Sample output**: 3,705 rows, 9,500 cards; columns include product_name, set_name, discriminator (e.g. `17/207`, promo `34/P2`, `3/RPH`, `14/PD1`), rarity (`Rare`, `Rare Cold Foil`, `Epic Foil`, `Promo Foil`, `Enchanted`...), quantity, value_per_unit, tcgplayer_id. Sets: all 14 main sets, Disney Lorcana Promos (71 printings), D23 Promos (3), Illumineer's Quest Deep Trouble + Palace Heist.
**Processing**: aggregate rows by tcgplayer_id -> per-card qty total + finish breakdown (regular / cold foil / epic foil / enchanted / promo foil) + market value_per_unit. `Sealed` rarity rows are booster boxes, not cards — excluded. At build time this is baked into a compact `server/src/ownership.json` the seed action imports (server actions cannot read workspace files).

### LorcanaJSON full card catalog (card universe + art + stats)
**Used by**: seedBinder (catalog rows, slimmed snapshot bundled server-side as fallback-free primary), source of every card's Ravensburger image path
**Test command**: `curl -sL 'https://lorcanajson.org/files/current/en/allCards.json'` (HTTP 200, 9,553,983 bytes)
**Sample output**: 3,556 cards; sets meta covers sets 1-14 (The First Chapter..Hyperia City), 15/16 future sets with 0 cards, quests Q1/Q2/Q3. Each card: fullName, setCode, number, rarity, foilTypes, externalLinks.tcgPlayerId, images.full = `https://api.lorcana.ravensburger.com/images/en/set1/1_ea50....jpg`. Set 1 rarities: 204 base + 12 Enchanted + 29 Special. Set 14: 204 base + 18 Epic + 18 Enchanted + 2 Iconic + 15 Special.
**Processing**: one binder slot per catalog card (set + collector number). Rarity `Special` cards are promos/special printings — their fullIdentifier suffix (`1/P1`, `01/D23`, `1/C1`, `1/CC1`, promo paths like `images/en/promo1/...`) assigns them to promo-binder families (P1, P2, P3, P4, PD1, D23, Challenge, others present) instead of the main set. Main-set cards group by setCode 1-14; quests Q1-Q3 get their own small section. Epics/Enchanteds/Iconics are numbered slots beyond the base count, exactly as his Shiny discriminators show (`207/204` etc.).

### Ravensburger official image CDN (real card art)
**Used by**: cardImage action (fetch once -> ctx.blobs cache -> blob URL), rendered for both owned (full color) and missing (ghosted) cards
**Test command**: `curl -sI 'https://api.lorcana.ravensburger.com/images/en/set13/1_9e5034ef64dbfe30344c5dace27116d15a8cf47f.jpg'`
**Sample output**: HTTP 200, `Content-Type: image/jpeg` — real official card scans as JPEG (not AVIF), for main sets, promos (`/images/en/promo1/`, `/images/en/d23/`, `/images/en/challenge1/`), and quests alike, via each catalog card's images.full URL.
**Processing**: lazy per-card fetch inside the action the first time a pocket is viewed; bytes stored with ctx.blobs (image/jpeg), only the blob key persisted in ctx.db. Client requests images only when a pocket nears the viewport (IntersectionObserver, ~900px margin), so the continuous scroll through a full set never downloads the ~3,500-image universe at once.

### Financial metrics section (added Nov 2, 2026; rebuilt same day to export-exact data)
**Requested by**: `Are there more? Can we add financial metrics to this binder?` + `like create like a section for it?` + per-card tab (`keep track of the card's individual value`) + charts (`I don't want just numerical values. I also want to see a chart.`) + history (`the chart starts from the time that we start this collection`) + daily updates (`I want you to update these financials daily.`)
**First-build defect, fixed**: the original ownership.ts applied ONE per-unit price to all finishes of a printing. In Shiny, Regular and Cold Foil rows share one TCGplayer id but carry different value_per_unit/paid_per_unit (e.g. foil $0.47 vs regular $0.14), so binder totals came out $5,405.86 against the export's true $4,418.05. ownership.ts was regenerated from the Nov 1, 2026 (11:27 PM) CSV with a per-finish breakdown (byFinish: qty + value/paid per unit per finish); quantities were unchanged (9,368 cards / 2,812 printings before and after). Join: TCGplayer id primary; (set, collector number) fallback for Hyperia City (catalog tcg ids absent/stale there); promo-family + number and name fallbacks for promos whose catalog entries carry no TCGplayer id. 0 rows unmatched.
**Tie-out (verified by recomputation from the CSV)**: binder scope 9,368 cards, value $4,100.71, paid $4,553.01; sealed products 14 items / $306.25 / $268.70; Ink Drop tokens + Floodborn puzzle pieces 118 items / $11.09 / $32.99 (counted in the export, not binder cards). Export scope total: 9,500 cards, $4,418.05 value, $4,854.70 paid, net −$436.65, avg $0.47/card — exactly the export's own sums. Foil-family finishes (Cold Foil, Epic Foil, Enchanted, Enchanted Foil, Promo Foil, Promo Cold Foil, Foil) hold $2,588.48. Per-set export aggregates (value/paid verified: Hyperia City $790.95/$1,213.79, Attack of the Vine! $496.58/$615.37, Whispers in the Well $431.23/$277.49, Disney Lorcana Promos $424.07/$495.86) are bundled in server/src/data/exportFinance.ts with the sealed item list.
**Used by**: getFinance (Finances tab: totals, value-over-time line chart, value-by-set and paid-vs-value charts, per-set table, most-valuable items merged cards+sealed, rarity chart, price tiers, spare/beyond-playset values) and getCard's finance block (card sheet Finances tab: per-finish value/paid, totals, gain/loss, paid-vs-value mini bar). Values compute live from stored per-finish prices x current counts; seedBinder backfills price fields (never counts) on load for binders seeded by the first build.
**History**: finance_snapshots table seeded with the five real export snapshots supplied by Anthony — Oct 25, 2026 ($4,419.58 / $4,685.34 / 9,336), Oct 27 ($4,419.98 / $4,731.20 / 9,437), Oct 29 ($4,485.73 / $4,855.63 / 9,446), Nov 1 first ($4,413.98 / $4,850.63 / 9,498), Nov 1 latest ($4,418.05 / $4,854.70 / 9,500). Oct 25 is labeled the start of tracked collection history; no earlier points exist or are invented. New exports (standing auto-update rule) and daily re-pricings append points.
**Daily re-pricing**: cron `lorcana-binder-daily-finance-refresh` (daily 06:30 America/Chicago, space_action) calls refreshFinance, which spawns an agent task (dedupeKey per day, expectsAction saveRepricing). The task lists owned printings via getRepricingTargets, fetches current USD prices (Lorcast API prices: usd / usd_foil), and saves via saveRepricing, which updates per-finish VALUES only (paid untouched) and appends that day's snapshot only when >=50% of owned printings were priced. The Finances tab also has a manual "Re-price now" button calling the same action.
**Per-card price history**: card_price_history table seeded from all five real export files on disk (each file's totals verified against the recorded snapshots before use — Oct 25 file sums to $4,419.58, Oct 27 to $4,419.98, Oct 29 to $4,485.73, Nov 1 first to $4,413.98, Nov 1 latest to $4,418.05) using the same join as ownership.ts: 14,035 points across 2,812 printings, each point the printing's quantity-weighted average value per copy at that export. The card sheet's Finances tab renders it as a classic Wikipedia-style line chart (white plot, single blue line with data points, gridlines, labeled axes — Anthony's reference style). saveRepricing appends/refreshes one daily point per priced card, so each card's chart also grows a point per day.
